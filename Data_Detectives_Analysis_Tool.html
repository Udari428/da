Data quality checks

Checks include blank cells, duplicate rows, repeated ID values, conflicting ID records, invalid numeric values and unparseable date values.

Manual cell edit

Every applied edit is recorded in the change log. Check the preview and document why a change is justified.

Descriptive statistics

Mode can have more than one value. Standard deviation here is population standard deviation (divide by N).

Charts and 1.5 × IQR outliers

Quartiles use the inclusive method (linear interpolation with p × (n − 1)). Fences are Q1 − 1.5 × IQR and Q3 + 1.5 × IQR. The same original fences are used when comparing the data with and without outliers.

Export cleaned data and change log

Export creates a new CSV. It does not overwrite the uploaded original.

The cleaned export removes exact duplicate rows. Repeated IDs with different values are flagged for review, not silently deleted.
